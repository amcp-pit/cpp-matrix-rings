# Кольца в матрице

Написать программу, заполняющую массив `(2n+1) x (2n+1)` числами по возрастанию "кольцами" из центра.
Наименьшее число в "кольце" в левом верхнем углу.
Числа в "кольце" располагаются по часовой стрелке.
В файл вывести матрицу, выровняв столбцы по левому краю.

Число `n` (не более 10000) и имя файла задаются аргументами командной строки.

Например, для вывода в файл `output.txt` матрицы 5х5 (для `n=2`):
```
   ./rings 2 output.txt
```
В результате содержимое файла должно быть:
```
10 11 12 13 14
25 2  3  4  15
24 9  1  5  16
23 8  7  6  17
22 21 20 19 18
```

## Требования
Программа не должна использовать контейнеры STL (std::vector, std::string и т. д.).
